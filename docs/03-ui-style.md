# 家庭点菜小程序 · UI 风格设计

> 版本：v1.0（草案） | 日期：2026-11-02
> 设计原则：像家人递过来的一张手写菜单，温暖、清楚、不费脑。

## 1. 设计定位（一句话）

> 一张随时打开都「看得懂、点得动」的手写菜单，厨房般温暖，又保留清单式的高效。

## 2. 设计原则

| 原则 | 说明 | 落点 |
|------|------|------|
| 一眼能懂 | 打开就知道「现在有一顿饭在开」 | 首页主打「进行中的饭」大卡片 |
| 点得动 | 触控优先，按钮够大 | 主按钮 ≥ 48px，行高充足 |
| 家庭感 | 去企业化、去电商感 | 暖色、圆角、手绘风图标、口语化文案 |
| 只做减法 | 每屏只突出一个主任务 | 单列布局，减少并列决策 |

## 3. 视觉风格

### 3.1 色彩

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色（橄榄/青） | `#5B8C5A` / `#4F7A4E` | 食材与健康感，用做大按钮、选中态、备齐 |
| 强调暖色（番茄红） | `#D96A3B` | 开饭按钮、「缺货」高亮 |
| 中性底色 | `#FAF6F0` | 奶油纸感背景 |
| 卡片 | `#FFFFFF` | 白卡片浮于暖底上 |
| 文字主 | `#3B342E` | 深棕灰，像纸上的字 |
| 文字次 | `#8A8077` | 灰棕 |
| 成功/备齐 | `#5B8C5A` | 与主色一致 |
| 警示/缺货 | `#C94F3D` | 番茄红系 |

### 3.2 字体与字号

- 中文优先 `system-ui / PingFang SC / Microsoft YaHei / Noto Sans SC`。
- 标题 20–22px，正文 16px，次级 13px；**库存粘贴框等输入不得小于 17px**（避免手机自动缩放）。
- 清晰层级：一屏只有一个 22px 主标题。

### 3.3 形状与质感

- 圆角：卡片 16px，按钮 12px，药丸标签 999px。
- 阴影：浅、低透明度，营造「纸片轻轻压在桌布上」的层次。
- 图标：线性手绘风，暖色描边；不用复杂渐变、不堆悬浮动效。
- 质感关键词：奶油纸、原木、棉麻、手写标签。

### 3.4 文案风格

- 家人聊天式口语，短句。
  - ✗「您已成功创建餐次」
  - ✓「今晚这顿饭开好啦，想吃什么？」
- 状态用「吃完了 / 备齐了 / 还差一点」，不用「已完成 / 审核中」。

## 4. 布局骨架

### 4.1 底部 Tab（手机）

```
[ 今天吃啥 ]  [ 菜谱 ]  [ 库存 ]  [ 日志 ]
```

- 「今天吃啥」承载开饭/点菜/备菜的主链路；其他三项是常备库。
- 中间可放一个凸起的橙色「＋开饭」FAB，快速发起主任务。

### 4.2 关键页面

| 页面 | 核心元素 | 效果 |
|------|----------|------|
| 首页·今天吃啥 | 顶部问候 + 进行中的饭大卡 + 历史归档 | 一张主卡即全部动作入口 |
| 饭局详情·点菜 | 已选菜品列表 + 「加一道菜」大按钮 | 家人只点一次 |
| 合并清单 | 缺额红标、备齐绿勾、按菜分组/汇总切换 | 主厨看货进度 |
| 备菜页 | 清单逐条 + 库存可用量 + 备齐开关 | 只勾状态、不扣库存 |
| 库存页 | 搜索 + 「粘贴录入」大入口 + 列表 | 快速整段导入 |
| 菜谱页 | 搜索 + 分类 chips + 卡片网格 | 浏览与「加入菜单」 |
| 菜谱详情 | 图 + 食材 + 步骤 + 「另存为我家版」 | 保留原版、fork 私版 |
| 日志页 | 月历栅格 + 每日小点 + 详情抽屉 | 一眼回顾本月 |

## 5. 交互与动效

- 点击反馈：主按钮按下微沉；勾选「备齐」用打勾弹跳 200ms。
- 页面切换：左右滑入（移动端原生感），不做长滚动广播。
- 合并去重过程可加一个「正在合并食材」的轻量状态，让用户理解发生了什么。
- 关键确认（删除菜谱/结束饭局）用底部弹出 sheet，忌用终端式 alert。

## 6. 无障碍与适配

- 关键文字与背景对比度 ≥ 4.5:1。
- 色盲友好：缺货不仅用红色，同时用「缺」文字与图标。
- 窄屏（320px）不横向滚动；所有列表单列布局。
- 支持深色模式（可选 V1.1）：深色下用暖灰底 + 柔化主色。

## 9. UI 验收标准

- [ ] 手机 30 秒内完成核心点菜链路。
- [ ] 主按钮全部 ≥ 48px 触控区。
- [ ] 缺货项同时用「颜色 + 文字 + 图标」表达。
- [ ] 输入框不触发手机自动缩放。
- [ ] 320px 最窄屏无横向滚动。
- [ ] 所有可点元素有按压/反馈状态。
